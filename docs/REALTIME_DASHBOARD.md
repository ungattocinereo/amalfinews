# Real-Time Dashboard 📊

## Обзор

Новый real-time дашборд предоставляет живой мониторинг системы сбора событий с обновлениями каждую секунду.

## Возможности

### 📈 Живая статистика
- **Статус системы**: отображение текущего состояния (idle, running, error)
- **Прогресс обработки**: real-time отслеживание обработки источников
- **Количество статей**: live подсчет найденных статей
- **Системные ресурсы**: CPU, память, размер БД, логи

### 🔄 Отслеживание прогресса
- Текущий обрабатываемый источник
- Прогресс-бар с процентами
- Количество обработанных/общих источников
- Статистика успешных/неудачных источников

### 📊 Дневная статистика
- Собрано статей (scraped)
- Переведено (translated)
- Одобрено (approved)
- Ожидает модерации (pending)
- Опубликовано (published)

### ⚠️ Мониторинг ошибок
- Последние 5 ошибок в real-time
- Информация об неудачных источниках

## Как использовать

### Запуск

```bash
# Через Docker
make start

# Или локально
uvicorn src.web.api:app --host 0.0.0.0 --port 8000
```

### Доступ к интерфейсу

После запуска откройте в браузере:

```
http://localhost:8000/dashboard
```

или просто:

```
http://localhost:8000/
```

(автоматически перенаправит на дашборд)

## Endpoints

### Веб-интерфейс

- `GET /` - Главная страница (редирект на дашборд)
- `GET /dashboard` - Real-time дашборд

### API endpoints

- `GET /api/realtime/stream` - Server-Sent Events stream для live обновлений
- `GET /api/realtime/stats` - REST endpoint для текущей статистики
- `GET /status` - Статус системы
- `GET /sources/health` - Проверка здоровья источников
- `GET /events/pending` - Ожидающие события
- `GET /events/recent` - Недавние события
- `POST /run` - Запустить ручную обработку

### API документация

- `GET /docs` - Swagger UI
- `GET /redoc` - ReDoc документация

### Server-Sent Events (SSE)

Дашборд использует SSE для получения обновлений каждую секунду без перезагрузки страницы.

Преимущества SSE:
- ✅ Односторонняя связь (сервер → клиент)
- ✅ Автоматическое переподключение
- ✅ Простая имплементация
- ✅ Работает через HTTP/HTTPS
- ✅ Поддерживается всеми современными браузерами

### Progress Tracking

`ProgressTracker` - глобальный singleton для отслеживания состояния операций:

```python
from src.monitoring.progress_tracker import progress_tracker

# Start operation
progress_tracker.start_operation(total_sources=11)

# Update current source
progress_tracker.update_source("amalfinews", "Amalfi News")

# Complete source
progress_tracker.complete_source("amalfinews", articles_count=36, success=True)

# Finish operation
progress_tracker.finish_operation()
```

## Визуальные индикаторы

### Статус системы

- 🟢 **RUNNING** - система активно обрабатывает источники
- 🟡 **IDLE** - система ожидает следующего запуска
- 🔴 **ERROR** - произошла ошибка

### Цветовая схема

- **Фиолетовый градиент** - основные элементы (#667eea → #764ba2)
- **Зеленый** - успешные операции (#10b981)
- **Желтый** - предупреждения (#d97706)
- **Красный** - ошибки (#ef4444)
- **Серый** - неактивные элементы (#6b7280)

### Анимации

- **Pulse** - мигание для активных статусов
- **Highlight** - подсветка обрабатываемого источника
- **Smooth transitions** - плавные переходы для прогресс-баров

## Troubleshooting

### Дашборд не обновляется

1. Проверьте консоль браузера (F12) на ошибки
2. Убедитесь что сервер запущен
3. Проверьте endpoint `/api/realtime/stream`

### Ошибка подключения SSE

```javascript
EventSource error: Failed to connect
```

**Решение**: Перезапустите сервер и обновите страницу

### Данные не отображаются

**Решение**: Убедитесь что база данных инициализирована:

```bash
make db-init
```

## Примеры использования

### Мониторинг активного процесса

1. Откройте дашборд
2. Запустите ручную обработку: `POST /run`
3. Наблюдайте за прогрессом в real-time

### Проверка здоровья источников

1. Откройте `/sources/health`
2. Посмотрите какие источники работают
3. При необходимости обновите селекторы в `config/sources.yaml`

### Отладка ошибок

1. В разделе "Recent Errors" видны последние ошибки
2. Проверьте логи для подробностей: `GET /logs/recent`
3. Исправьте проблемные источники
